# 総合買取チェッカー：追加ジャンル v2（取得先7店舗）

既存のiPhoneチェッカーと同じページで、ゲーム機・トレカ・カメラ・家電・その他を切り替えます。

## 初期対応

- 登録商品8件：Switch 2本体2種、テラスタルフェスex BOX、instax mini Evo 3色、ナノケア2種。
- 商品名・型番・JAN検索、商品価格順／名前順、店舗別価格順位、仕入れ・送料・費用を引いた手残り試算。
- 対応取得先：ホムラ、ルデヤ、森森、携帯空間、買取wiki、買取商店、買取一丁目。商品ごとに条件を確認でき、取得に成功した店舗だけを順位に反映します。全商品で7店舗の価格が揃うという意味ではありません。
- 買取商店は公式サイトの公開検索APIの通常基準価格を取得。来店加算は金額に加えず、備考を表示します。
- 買取一丁目は公式サイトの公開検索APIから新品の条件別買取価格を取得。定価・キャンペーン最大価格は採用しません。数量制限や減額注意も備考に表示します。
- 携帯空間は新品・未使用・未開封の欄を使用。買取wikiはJANが一致する商品カード単位で取得し、中古商品を除外します。
- 今回追加した店舗のトレカは、シュリンクありを確認できない価格を除外します。買取商店の購入証明など、追加条件は備考を確認してください。
- 価格が取得できた店舗だけ表示。取得失敗・対象条件なし・曖昧な価格は順位対象外。36時間超の観測値も順位に入れません。
- トレカは未開封BOX・シュリンクありのみ。シングル／鑑定品／シュリンクなし／カートンは未対応。
- その他カテゴリは商品未登録です。検索対象は登録商品のみで、未登録JANの即時横断検索ではありません。
- 人気ランキング、バーコード撮影、任意商品の即時取得は今回未実装です。

## 更新

```sh
python3 -u scripts/crawl_catalog.py
```

Python標準ライブラリのみ（GitHub Actionsは3.12、コードは3.9対応構文）。data/catalog_prices.jsonを更新します。既存のiPhone価格ファイル・クローラーは変更しません。

GitHub Actionsの「Update multi-category buyback prices」を手動実行できます。mainに反映後は毎日08:20 JSTに実行予定です。GitHub側のスケジュール遅延はあり得ます。

失敗した価格は前回値で補いません。実際の支払額・送料・商品状態・数量条件を各店で確認してください。費用入力は全店舗共通の試算で、店舗固有の送料・手数料を自動取得するものではありません。

## 商品追加

1. data/catalog.jsonにid、category、name、jan、condition、identity_sourceを登録。
2. categoryはgames / cards / cameras / appliances / other。
3. conditionはnew、またはsealed_box。JANは公開情報で確認した13桁文字列。
4. 店舗独自コードはstore_codesに店舗別で明示。ホムラのBOXコードはJANと区別して登録し、部分一致では検索結果を採用しません。
5. 取得を実行しmatched_nameと公式リンクを目視照合してから公開。

同じJANでもパック／BOX、シュリンク有無、言語、型番違いなどが混ざる場合は別商品・条件として登録します。商品名だけの曖昧一致で価格を採用しません。

## 確認

```sh
python3 -m unittest discover -s tests -p 'test_catalog.py'
node --test tests/catalog-core.test.js
```

21テスト（Python18件・Node3件）でJAN完全一致、中古除外、BOX条件、価格の混入防止、取得失敗・古い価格除外、検索、損失を含む手残り計算を確認。v2では定価・キャンペーン最大額・来店加算の混入、別JAN、未確定価格、非表示商品、検索結果の途中打ち切り、異なる買取価格の競合も確認します。

初版のブラウザ確認項目：デスクトップ／390px幅、ジャンル切替、JAN検索、商品詳細、費用入力、取得失敗表示、空カテゴリ、iPhone画面への復帰、横はみ出し。v2は画面のHTML・CSS・JavaScriptを変更せず、同じデータ形式で取得先を増やします。
