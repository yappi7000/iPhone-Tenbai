# 総合買取チェッカー：追加ジャンル v3（Android・ポケモン30周年・買取ベスト5）

既存のiPhoneチェッカーと同じページで、ゲーム機・トレカ・カメラ・家電・その他を切り替えます。

## 初期対応

- JAN登録商品60件：既存8商品、30周年12商品とAndroid40商品（色・容量違いを別商品として登録）。AndroidはPixel 9a / 10a、arrows We2 / We3、AQUOS wish5 / sense10、Galaxy A25、OPPO Reno13 A、Xperia 10 VII。対応する色・容量・販売元は登録商品一覧で確認してください。
- 商品名・型番・JAN検索、商品価格順／名前順、店舗別価格順位、仕入れ・送料・費用を引いた手残り試算。
- 対応取得先：ホムラ、ルデヤ、森森、携帯空間、買取wiki、買取商店、買取一丁目。商品ごとに条件を確認でき、取得に成功した店舗だけを順位に反映します。全商品で7店舗の価格が揃うという意味ではありません。
- 買取商店は公式サイトの公開検索APIの通常基準価格を取得。来店加算は金額に加えず、備考を表示します。
- 買取一丁目は公式サイトの公開検索APIから新品の条件別買取価格を取得。定価・キャンペーン最大価格は採用しません。数量制限や減額注意も備考に表示します。
- 携帯空間は新品・未使用・未開封の欄を使用。買取wikiはJANが一致する商品カード単位で取得し、中古商品を除外します。
- 今回追加した店舗のトレカは、シュリンクありを確認できない価格を除外します。買取商店の購入証明など、追加条件は備考を確認してください。
- 価格が取得できた店舗だけ表示。取得失敗・対象条件なし・曖昧な価格は順位対象外。36時間超の観測値も順位に入れません。
- トレカは「BOX・セット」「30周年」「シングル」「買取ベスト5」「すべて」で切り替え。検索文字を入力すると全トレカが検索対象になります。
- 30周年はCELEBRATION BOX、エーフィ・ブラッキーのプレミアムデッキ、FUTURISTIC BOX、カードセット9種。未開封セットは明示された未開封条件が必須。available_fromより前の商品は検索には表示しますが、取得・順位の対象外です。発売日は日本時間で判定します。
- シングルはカードラッシュの公開買取一覧先頭100件と、もえたく！の登録5商品を取得。通常の公開買取額を使い、販売価格・推定買取額・落札額・キャンペーン上乗せ額を採用しません。版・カード番号・未開封条件を分けます。PSA等の鑑定品は対象外です。
- 「買取ベスト5」は取得済みシングルカードの各商品について、36時間以内の有効な最高買取価格で上位5商品を表示。同額は同順位です。市場全体のランキングではなく、登録・取得できた範囲の順位です。
- ポケモンイラストレーター、初版かいりきリザードン、ブラッキー☆、リーリエSRも検索できます。トロフィーピカチュウNo.1/No.3は版・大会を特定した公開買取価格を確認できていないため、参考項目として検索できますが順位には入りません。
- 「その他・Android」でAndroidを検索できます。日本語の別名（ピクセル、アクオス、アローズ等）・全角・空白やハイフンを省いた型番にも対応。検索対象は登録商品のみです。未登録商品は入力語を引き継いだ6店の公式検索リンクから確認でき、未登録商品の価格はその場でランキングに追加されません。
- Androidは新品・未使用が対象です。未開封指定・キャリア版の可否・利用制限・数量制限などは店舗別に確認してください。同一JANが確認できない店舗は除外します。
- 買取一丁目のAndroidは公式検索の色別JANと条件IDを照合し、通常基準額＋色別差額を採用。UPC12桁はチェック桁を検証したうえで先頭0のJAN13桁と同一扱いにします。開封・中古の価格やキャンペーン最大額は採用しません。
- 人気ランキング、バーコード撮影、任意商品の即時取得は今回未実装です。

## 更新

```sh
python3 -u scripts/crawl_catalog.py
```

店舗ごとに1本の処理で順番に取得し、各取得後に1秒待ちます。7店舗の処理は並列です。商品数が増えたため、全体の更新には数分〜十数分かかる場合があります。

Python標準ライブラリのみ（GitHub Actionsは3.12、コードは3.9対応構文）。data/catalog_prices.jsonとdata/pokemon_market.jsonを更新します。既存のiPhone価格ファイル・クローラーは変更しません。

GitHub Actionsの「Update multi-category buyback prices」を手動実行できます。mainに反映後は毎日08:20 JSTに実行予定です。GitHub側のスケジュール遅延はあり得ます。

失敗した価格は前回値で補いません。実際の支払額・送料・商品状態・数量条件を各店で確認してください。費用入力は全店舗共通の試算で、店舗固有の送料・手数料を自動取得するものではありません。

## 商品追加

1. data/catalog.jsonにid、category、name、jan、condition、identity_sourceを登録。
2. categoryはgames / cards / cameras / appliances / other。
3. conditionはnew、sealed_box、またはsealed_set。JANは公開情報で確認した13桁文字列。
4. 店舗独自コードはstore_codesに店舗別で明示。ホムラのBOXコードはJANと区別して登録し、部分一致では検索結果を採用しません。
5. Androidはcategory: other、kind: androidとし、aliasesに日本語の別名、modelに型番を登録できます。一丁目のスマホ検索にはstore_queries.ichomeへ機種名を登録（候補取得用にのみ使い、価格の採否は色別JAN完全一致で決定）。identity_sourceには商品名とJANを確認した公式店舗の商品ページを記録します。
6. 取得を実行しmatched_nameと公式リンクを目視照合してから公開。

同じJANでもパック／BOX、シュリンク有無、言語、型番違いなどが混ざる場合は別商品・条件として登録します。商品名だけの曖昧一致で価格を採用しません。
